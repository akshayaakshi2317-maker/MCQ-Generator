#  AI MCQ Generator

An interactive Multiple-Choice Question (MCQ) Generator built using Python and Streamlit.

This application generates multiple-choice questions from user-provided study material and displays the questions, options, correct answers, and explanations.

##  Features

-  Enter study material
-  Select the number of questions
-  Select difficulty level
-  Generate multiple-choice questions
-  Display four answer options
-  Show the correct answer
-  Provide explanations
-  Simple and interactive Streamlit interface

##  Technologies Used

- Python
- Streamlit
- Regular Expressions
- Random Module

##  How It Works

1. The user enters study material.
2. The user selects the number of questions.
3. The user selects the difficulty level.
4. The application processes the study material.
5. Sentences and words are extracted from the content.
6. MCQs are generated with four options.
7. The correct answer and explanation are displayed.

##  Application Output

The application displays:

Generated MCQ questions
Four answer options
Correct answer
Explanation for each question
